# Project

Micro SaaS MVP project for a Vibe Coding class.

# Product Idea

This app helps job seekers manage scattered career assets (certifications, language scores, extracurriculars, job applications, resumes, portfolios) by consolidating them into a single dashboard with AI-assisted resume review.

See `docs/PRD.md` for full product requirements.

# Tech Stack

**Frontend**
- React (Vite)
- TypeScript
- Tailwind CSS
- React Router

**Backend**
- Spring Boot (Java)
- REST API

**Common**

- GitHub
