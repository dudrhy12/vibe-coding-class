# Requirements Spec

> 본 문서는 `planning/md-design/01_PRODUCT_BRIEF.md`의 MVP 범위를 기준으로 한다.

## 1. Actors

| Actor | Description |
|---|---|
| Primary User | 취업 준비생 (대학교 3-4학년 ~ 졸업 후 1-2년). 자격증·어학·대외활동·채용 일정·이력서·포트폴리오를 병행 관리하는 사용자. |
| Optional Admin | 이번 MVP에서는 제외 — 단일 사용자 기준으로 처리한다. 모든 데이터는 본인 소유. |

## 2. Main Use Cases

### UC-001. 핵심 항목 생성 (자격증/어학 점수 등록)

- **Actor:** Primary User
- **Goal:** 보유한 자격증 또는 어학 점수를 시스템에 등록하여 한 곳에서 관리한다.
- **Precondition:** 사용자가 `/app` 대시보드에 접속한 상태.
- **Main Flow:**
  1. 좌측 네비에서 "자격증" 메뉴를 선택한다.
  2. "추가" 버튼을 눌러 등록 폼을 연다.
  3. 자격증명, 점수/등급, 취득일, 만료일(선택), 발급기관을 입력한다.
  4. 사본 이미지/PDF를 선택적으로 업로드한다 (5MB 이하).
  5. "저장" 버튼을 누른다.
- **Alternative Flow:**
  - 필수값(자격증명, 취득일) 누락 → 폼에 오류 메시지 표시, 저장 차단.
  - 5MB 초과 파일 업로드 시도 → 업로드 거부 + 사이즈 안내.
- **Result:** 자격증 목록 상단에 새 항목이 표시된다. 만료일이 30일 이내라면 대시보드 알림 영역에도 함께 표시된다.

### UC-002. 목록 확인 (스펙 대시보드 조회)

- **Actor:** Primary User
- **Goal:** 등록한 자격증·활동·공고·이력서·포트폴리오를 분류별로 확인한다.
- **Precondition:** 1개 이상의 항목이 등록되어 있다.
- **Main Flow:**
  1. `/app` 대시보드로 진입한다.
  2. 상단에 임박 마감일·자격증 만료 알림이 표시된다.
  3. 좌측 네비에서 카테고리(자격증 · 활동 · 공고 · 이력서 · 포트폴리오)를 전환한다.
  4. 각 카테고리는 카드 또는 리스트 뷰로 항목을 보여준다.
- **Alternative Flow:**
  - 항목이 0개인 카테고리는 빈 상태 화면 + "추가하기" CTA를 표시한다.
- **Result:** 사용자가 카테고리별로 등록한 모든 항목을 1분 안에 훑어볼 수 있다.

### UC-003. 상태 변경 (채용 공고 진행 단계 업데이트)

- **Actor:** Primary User
- **Goal:** 지원한 채용 공고의 진행 단계를 업데이트하여 진행 상황을 추적한다.
- **Precondition:** 채용 공고가 1개 이상 등록되어 있다.
- **Main Flow:**
  1. "채용 공고" 메뉴에 진입한다.
  2. 대상 공고 카드를 선택한다.
  3. 현재 단계(서류 → 코딩테스트 → 면접 1차 → 면접 2차 → 결과) 중 다음 단계를 선택한다.
  4. 선택 사항으로 메모를 입력한다 (예: 면접 후기, 다음 일정).
  5. "저장" 버튼을 누른다.
- **Alternative Flow:**
  - 이전 단계로 되돌리기 가능 (실수 정정).
  - 결과 단계(합격/불합격/대기) 선택 시 별도 색상으로 표시.
- **Result:** 공고 상세 페이지에 변경된 단계와 메모가 기록되고, 대시보드 진행률에 즉시 반영된다.

### UC-004. 필터 또는 검색 (대외활동 태그 필터)

- **Actor:** Primary User
- **Goal:** 보유한 대외활동을 태그로 필터링하여 회사별로 어필할 활동을 골라낸다.
- **Precondition:** 대외활동이 1개 이상 등록되어 있고 태그가 부여되어 있다.
- **Main Flow:**
  1. "대외활동" 메뉴에 진입한다.
  2. 상단의 태그 칩(예: "마케팅", "데이터", "리더십") 중 1개 이상을 선택한다.
  3. 목록이 선택한 태그를 포함한 활동만 보이도록 즉시 필터링된다.
- **Alternative Flow:**
  - 태그 선택 해제 시 전체 목록으로 복귀.
  - 매칭 결과가 0건일 경우 "조건에 맞는 활동이 없습니다" 안내.
- **Result:** 사용자가 회사 지원 컨텍스트에 맞는 활동만 골라서 확인할 수 있다.

## 3. Functional Requirements

| ID | Requirement | Priority |
|---|---|---|
| FR-001 | 사용자는 자격증·어학·활동·공고·이력서·포트폴리오 항목을 생성할 수 있다. | Must |
| FR-002 | 사용자는 분류별 항목 목록을 카드 또는 리스트 뷰로 확인할 수 있다. | Must |
| FR-003 | 사용자는 채용 공고의 진행 단계를 변경할 수 있다. | Must |
| FR-004 | 사용자는 활동을 태그로 필터링하고, 공고를 마감일 기준으로 정렬할 수 있다. | Should |
| FR-005 | 사용자는 등록한 항목을 수정하거나 삭제할 수 있다. | Should |
| FR-006 | 사용자는 이력서 작성 화면에서 글자수 카운터를 실시간으로 확인할 수 있다. | Must |
| FR-007 | 사용자는 Claude API 기반 AI 점검(맞춤법·문장 다듬기)을 이력서에서 호출할 수 있다. | Should |
| FR-008 | 사용자는 자격증 만료 30일 전 항목을 대시보드 상단에서 확인할 수 있다. | Should |
| FR-009 | 사용자는 포트폴리오 항목을 묶어 회사별 "패키지"를 만들 수 있다. | Nice |

## 4. Non-functional Requirements

| ID | Requirement |
|---|---|
| NFR-001 | 모바일 화면(< 768px)에서도 핵심 기능(생성·조회·상태 변경)을 사용할 수 있어야 한다. |
| NFR-002 | 버튼·입력 필드·아이콘 버튼은 접근 가능한 이름(`aria-label` 또는 가시 레이블)을 가져야 한다. |
| NFR-003 | 민감한 정보(자격증 사본, API 키, DB 자격 증명)는 GitHub 저장소에 커밋하지 않는다. `.env`는 `.gitignore`에 포함한다. |
| NFR-004 | 기본 MVP는 단일 사용자 기준으로 구현한다. 멀티 테넌시 고려 없음. |
| NFR-005 | 자격증·포트폴리오에 첨부하는 파일은 5MB 이하 이미지/PDF만 허용한다. |
| NFR-006 | Claude API 호출은 사용자당 일일 호출 횟수 상한(임시 20회/일)을 적용해 비용을 통제한다. |
| NFR-007 | UI는 `docs/DESIGN.md`의 BMW M 스타일 가이드(검정 캔버스 + UPPERCASE 헤드라인 + 0px 보더 라디우스)를 따른다. |
| NFR-008 | 대시보드 초기 렌더는 일반 회선에서 3초 이내에 완료되어야 한다. |

## 5. Acceptance Criteria

### AC-001. 항목 생성 (자격증 등록)

Given 사용자가 자격증명·취득일 등 필수 입력값을 작성했을 때
When "저장" 버튼을 누르면
Then 새 항목이 자격증 목록 상단에 표시된다.

### AC-002. 목록 확인 (대시보드 진입)

Given 1개 이상의 자격증·활동·공고가 등록되어 있을 때
When 사용자가 `/app` 화면을 열면
Then 좌측 네비에서 선택한 카테고리의 항목 목록이 표시된다.

### AC-003. 상태 변경 (채용 공고 단계 업데이트)

Given 공고 목록에 진행 중인 공고가 있을 때
When 사용자가 공고 상세에서 다음 단계 버튼을 누르면
Then 해당 공고의 진행 단계가 변경되고 대시보드 진행률에 즉시 반영된다.

### AC-004. 필터 (활동 태그 필터)

Given 여러 태그가 부여된 활동들이 등록되어 있을 때
When 사용자가 특정 태그 칩을 선택하면
Then 해당 태그를 포함한 활동만 목록에 표시된다.

### AC-005. 글자수 카운터 (이력서 작성)

Given 사용자가 글자수 제한(예: 1000자)을 설정한 이력서를 작성 중일 때
When 입력 영역에 텍스트를 입력하면
Then 현재 글자수 / 제한 글자수가 실시간으로 갱신되고, 제한 초과 시 카운터가 강조 색으로 바뀐다.

### AC-006. AI 이력서 점검

Given 사용자가 이력서 본문에 1자 이상 입력한 상태일 때
When "AI 점검" 버튼을 누르면
Then 맞춤법 교정 및 문장 다듬기 제안이 원문과 비교 가능한 형태로 표시된다.
