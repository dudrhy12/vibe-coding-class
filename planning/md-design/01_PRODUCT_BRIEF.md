# Product Brief

## 1. Product Summary

이 서비스는 **취업 준비생**이 **흩어져 있는 취업 준비 자료(자격증·어학·대외활동·채용 공고·이력서·포트폴리오)를 통합 관리하지 못해 마감일을 놓치고 이력서 버전이 꼬이는 문제**를 **단일 대시보드에서 모든 스펙·일정·산출물을 한 번에 관리하고 AI로 이력서를 점검하는 행동**으로 해결하도록 돕는다.

## 2. Problem

취업 준비생은 자격증 사본은 구글 드라이브에, 어학 점수는 메모장에, 대외활동 이력은 노션에, 채용 일정은 캘린더와 엑셀에, 이력서는 한컴/워드에, 포트폴리오는 노션과 깃허브에 흩어 저장하면서 도구를 계속 오가야 한다. 이 분산 구조 때문에 자격증 만료일·서류 마감일을 놓치는 일이 빈번하고, 회사별로 이력서를 조금씩 고치다 보면 어느 게 최신본인지 헷갈린다. ChatGPT 같은 AI 도구는 사용하지만 취업 맥락에 특화된 흐름이 없어 매번 프롬프트를 새로 작성해야 한다. 결과적으로 정보 정리에 쓰는 시간이 실제 지원 활동보다 길어지는 비효율이 발생한다.

## 3. Target User

- **주요 사용자:** 대학교 3-4학년 ~ 졸업 후 1-2년 이내의 취업 준비생. 동시에 5개 이상 채용 공고를 추적하며 자격증·어학·대외활동을 병행 관리해야 하는 상황.
- **사용 상황:** 주로 노트북 브라우저에서 사용. 채용 공고 마감 직전, 이력서 작성 직전, 면접 일정 정리 시점에 집중적으로 접근.
- **사용자의 기술 수준:** 디지털 도구 사용에 익숙함(노션·구글 드라이브·캘린더 일상 사용). 코딩은 못해도 대시보드형 SaaS는 무리 없이 다룸.
- **사용자가 기대하는 결과:** "내 스펙 한 화면에서 보고 싶다", "마감 놓치고 싶지 않다", "이력서 회사별 버전 헷갈리지 않게 관리하고 싶다", "AI가 글자수 맞춰 다듬어 줬으면 좋겠다".

## 4. Core Value

흩어져 있던 취업 준비 자료를 한 대시보드에 모아주고, 마감 알림과 AI 이력서 보조로 **취업 준비 과정의 인지 부하를 절반으로 줄인다**.

## 5. MVP Scope

이번 MVP에 포함할 것:

- **자격증 & 어학 점수 관리** — 항목 등록/수정/삭제, 사본 업로드, 만료 30일 전 대시보드 강조
- **대외활동 정리 대시보드** — 활동 등록(역할/성과/기간/태그), 태그 기반 필터
- **채용 공고 일정 & 진행 상황 관리** — 공고 등록(회사/직무/마감일/URL), 단계별 진행 상태(서류→코딩테스트→면접 1차→면접 2차→결과), 마감일 강조
- **AI 이력서 보조** — 회사별 이력서 버전 관리, 글자수 카운터(공고별 제한 설정), Claude API 기반 맞춤법·문장 다듬기
- **포트폴리오 관리** — 항목 등록(기간/사용 기술/링크/이미지), 회사 지원용 "패키지" 묶음 생성

## 6. Non-goals

이번 MVP에서 제외할 것:

- 로그인 (복잡한 OAuth 다종 연동 — 단일 인증만 사용)
- 결제 / 유료 플랜
- 실시간 협업 (이력서 공동 편집 등)
- 대용량 파일 업로드 (자격증 사본은 5MB 이하)
- 다중 외부 API 연동 (AI는 Claude API 1종만)
- 복잡한 관리자 권한
- 채용 공고 자동 크롤링
- 면접 후기 커뮤니티
- 모바일 네이티브 앱

## 7. Success Criteria

- 사용자는 핵심 기능을 1분 안에 사용할 수 있다.
- 3회차 종료 시 브라우저에서 기본 흐름을 확인할 수 있다.
- 4회차에서 핵심 흐름을 Playwright 테스트로 검증할 수 있다.
- 최종 결과물은 배포 가능한 형태여야 한다.
