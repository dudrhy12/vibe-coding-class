# PRD — 취업 준비생 스펙 & 경력 관리 웹앱

> **상태:** Draft v0.1 · Session 1 (2026-05-27)
> **버전 관리:** 변경 시 상단 날짜와 버전 갱신

---

## 1. 개요

취업 준비생이 자격증, 어학 점수, 대외활동, 채용 일정, 이력서, 포트폴리오 등 **흩어져 있는 취업 준비 자료를 한 곳에서 정리·관리**할 수 있는 웹 SaaS.

현재 취업 준비생은 자격증 사본은 구글 드라이브, 어학 점수는 메모장, 채용 일정은 캘린더 또는 엑셀, 이력서는 한글/워드, 포트폴리오는 노션 등 여러 도구에 정보가 분산되어 있어 **마감 임박 시 일정 누락, 이력서 버전 혼란, 자격증 만료일 누락** 등의 문제가 발생함. 본 서비스는 이 모든 정보를 **하나의 대시보드**에서 관리하고, **AI 기반 이력서 보조**까지 제공하여 취업 준비 과정의 인지 부하를 낮춘다.

가칭(둘 중 택1 또는 새 안 제안 가능):
- **SpecBook** — 스펙을 책처럼 정리한다는 메타포
- **JobTrack** — 채용을 추적·관리한다는 직관적 명칭

---

## 2. 타겟 사용자

### 주 사용자
- **취업 준비생** (대학교 3-4학년 / 졸업 후 1-2년 이내)
- 다수의 채용 공고에 동시 지원하면서 자격증·어학·대외활동·이력서·포트폴리오를 병행 관리해야 하는 사용자

### 사용자 특성
- 디지털 도구에 익숙하지만 **여러 도구를 오가는 피로감**을 느낌
- 자격증 만료일·시험 일정·서류 마감일을 **수동으로 관리하다 누락한 경험**이 있음
- 이력서를 회사별로 조금씩 수정하면서 **버전 관리에 어려움**을 겪음
- AI 도구(ChatGPT 등)는 사용하지만, **취업 맥락에 특화된 도구가 없어** 매번 프롬프트를 새로 작성

---

## 3. 문제 정의

| 문제 | 현재 해결 방식 | 한계 |
|---|---|---|
| 자격증·어학 점수 사본/정보 분산 | 구글 드라이브, 사진첩, 메모장 | 만료일 알림 없음, 검색 불편 |
| 대외활동 이력 정리 부족 | 노션, 엑셀, 워드 | 이력서 작성 시 다시 정리해야 함 |
| 채용 공고별 일정·진행 상황 추적 | 캘린더 + 엑셀 + 메모 | 마감 임박 알림·단계별 진행률 미흡 |
| 이력서 작성 시 맞춤법·글자수 체크 | 한컴/워드 + 별도 맞춤법 검사기 | 채용공고 자기소개서 글자 제한 대응 비효율 |
| 포트폴리오 산출물 관리 | 노션·깃허브·드라이브 산재 | 회사별로 강조 항목 다르게 보여주기 어려움 |

## 4. 핵심 가치 제안

- **한 곳에서 모든 취업 자료 관리** — 자격증, 어학, 대외활동, 이력서, 포트폴리오, 채용 일정을 단일 대시보드에서.
- **자동 알림** — 자격증 만료, 시험 일정, 서류 마감을 놓치지 않도록.
- **AI 이력서 보조** — 글자수 제한, 맞춤법, 문장 다듬기를 한 화면에서.
- **회사별 맞춤 패키지** — 채용 공고별로 어떤 자격증·활동·포트폴리오 항목을 강조할지 선택.

## 5. MVP 핵심 기능

> 우선순위 기준: **P0** = MVP 필수 / **P1** = MVP 포함 권장 / **P2** = 차기 버전

### F1. 자격증 & 어학 점수 관리 (P0)
- 자격증/어학 점수 항목 등록 (이름, 점수/등급, 취득일, 만료일, 발급기관)
- 이미지/PDF 사본 업로드 (사본 미리보기)
- 만료일 임박 항목 대시보드 강조
- 리스트 / 카드 뷰 토글

**완료 정의 (DoD):**
- 사용자가 자격증을 추가/수정/삭제할 수 있다
- 만료 30일 전 항목이 대시보드 상단에 표시된다

### F2. 대외활동 정리 대시보드 (P0)
- 활동 항목 등록 (활동명, 기간, 역할, 주요 성과, 관련 태그)
- 태그 기반 필터 (예: "마케팅", "데이터", "리더십")
- 활동별 첨부 자료 링크 (외부 URL)

**완료 정의 (DoD):**
- 활동을 추가하고 태그로 필터링할 수 있다
- 활동 상세 페이지에서 성과·역할을 확인할 수 있다

### F3. 채용 공고별 일정 & 진행 상황 관리 (P0)
- 공고 등록 (회사, 직무, 마감일, 공고 URL)
- 단계별 진행 상태 (서류 → 코딩테스트 → 면접 1차 → 면접 2차 → 결과)
- 마감일 기준 정렬 / 캘린더 뷰
- 단계 변경 시 메모 기록

**완료 정의 (DoD):**
- 공고를 추가하고 진행 단계를 업데이트할 수 있다
- 마감일이 임박한 공고가 시각적으로 강조된다

### F4. AI 이력서 보조 (P1)
- 이력서 에디터 (회사별 버전 관리)
- 글자수 카운터 (공고별 제한 글자수 설정 가능)
- AI 맞춤법/문법 검사 (Claude API 활용)
- AI 문장 다듬기 제안 (원문 / 제안문 비교 뷰)

**완료 정의 (DoD):**
- 이력서를 작성하면서 실시간으로 글자수가 보인다
- "AI 점검" 버튼으로 맞춤법·문장 제안을 받을 수 있다

### F5. 포트폴리오 관리 (P1)
- 포트폴리오 항목 등록 (프로젝트명, 기간, 사용 기술, 설명, 링크/이미지)
- 항목별 공개/비공개 토글
- 회사 지원 시 선택적으로 묶어서 보여주는 "패키지" 생성

**완료 정의 (DoD):**
- 포트폴리오 항목을 추가하고 패키지로 묶을 수 있다
- 패키지별 공유 가능한 미리보기 화면이 있다

## 6. 사용자 흐름 (Happy Path)

```
1. 랜딩(/) → 가입/로그인
2. 온보딩: 자격증·어학 1건 등록 (가이드 투어)
3. /app 대시보드 진입
   ├─ 상단: 임박한 마감/만료 알림
   ├─ 좌측 네비: 자격증 · 활동 · 공고 · 이력서 · 포트폴리오
   └─ 우측: 최근 업데이트 피드
4. 채용 공고 등록 → 이력서 작성 → AI 점검 → 포트폴리오 패키지 첨부 → 지원 완료 체크
```

## 7. 성공 지표 (가설 검증용)

| 지표 | 목표 | 측정 방법 |
|---|---|---|
| 활성 사용자가 등록한 평균 자격증 수 | ≥ 3개 | DB 집계 |
| 채용 공고 등록 후 단계 업데이트율 | ≥ 50% | 등록 공고 중 1회 이상 단계 변경 비율 |
| AI 이력서 점검 사용률 | ≥ 30% | 이력서 작성 사용자 중 AI 점검 1회 이상 사용 비율 |
| 7일 리텐션 | ≥ 25% | 가입 후 7일 내 재방문 비율 |

## 8. 범위 외 (Out of Scope, MVP 제외)

`CLAUDE.md`의 **Boundaries**에 따라 다음 항목은 MVP에 포함하지 않는다:

- 결제 / 유료 플랜
- 복잡한 인증 (소셜 로그인 1종 또는 이메일/패스워드 단순 인증만)
- 실시간 협업 (이력서 공동 편집 등)
- 대용량 파일 업로드 (자격증 사본은 ≤ 5MB)
- 다수의 외부 API 통합 (AI는 Claude API 1종만)

**기능 차원의 제외 항목:**
- 채용 공고 자동 크롤링 (사용자가 수동 등록)
- 면접 후기 커뮤니티
- 이력서 PDF 자동 생성 디자인 템플릿 다수 제공 (1-2종만)
- 모바일 네이티브 앱 (반응형 웹만)

**프론트엔드:**
- React (Vite) + TypeScript
